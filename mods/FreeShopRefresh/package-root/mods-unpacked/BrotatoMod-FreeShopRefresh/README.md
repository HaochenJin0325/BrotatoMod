# BrotatoMod-FreeShopRefresh

For Brotato **1.2.0.1** with ModLoader **6.2.0**.

Shop rerolls and upgrade-selection rerolls cost zero. The shop price is changed
through `ItemService.get_reroll_price()` so the mod does not need to extend the
shop's base class. Upgrade rerolls retain their existing UI extension.

Mod ID: `BrotatoMod-FreeShopRefresh`.
