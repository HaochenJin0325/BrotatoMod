# BrotatoMod-DiscountedRerolls

For Brotato **1.2.0.1** with ModLoader **6.2.0**.

Shop and upgrade-selection rerolls cost 40% of the price calculated by the game (a 60% reduction). Prices are rounded down to an integer and can be zero.

Mod ID: `BrotatoMod-DiscountedRerolls`.

Do not enable `BrotatoMod-FreeShopRefresh` at the same time. Its upgrade UI extension sets upgrade rerolls to zero.
