# All Starting Weapons

For Brotato **1.2.0.1** with ModLoader **6.2.0**.

At the weapon selection screen, this mod shows weapons from every tier available in the current game content, instead of only the selected character's original starting list. The candidate pool includes weapons from DLC item sets that are available and enabled. Locked weapons from loaded item sets are offered too, and the random choice uses the expanded list.

Character rules that prohibit melee or ranged weapons are still respected, as are DLC/item-set availability checks. DLC that is not owned, available, or enabled in the current content settings cannot be offered by the game.

The compatible older idea, “All Starting Weapons,” was for Brotato **0.6.0.7** and replaced the game's PCK, so this project recreates the behavior as a ModLoader extension for 1.2.0.1.
